# Google / Gemini

助手、研究、创作、搜索、编程与开放模型

先介绍业务线，再按用户选择执行对应产品卡。所有入口是官方资料起点，操作时重新核对当日状态。

| 产品 | 适用用途 | 支持路线 |
|---|---|---|
| Gemini | 大众 AI 助手 | WEB / APP |
| Gemini Notebook（原 NotebookLM） | 基于来源的学习与研究 | WEB / APP |
| Google Flow | AI 图像与视频创作 | WEB |
| Google Search AI Mode | AI 搜索 | WEB |
| Google Antigravity | 代理开发环境 | APP / CLI |
| Gemini Code Assist | IDE 编程辅助 | EXT |
| Jules | 云端编程代理 | WEB |
| Google AI Studio / Gemini API / Vertex AI | 模型体验和开发服务 | WEB / API |
| Gemma | 开放权重模型 | LOCAL |
| Veo | 视频生成 | WEB / API |
| Imagen | 图像生成 | WEB / API |
| Lyria | 音乐生成 | WEB / API |
| Whisk / Google Labs 创作实验 | 视觉参考与实验功能 | WEB |
| Gemini in Workspace | 文档、表格、邮件和办公 AI | WEB / EXT |
